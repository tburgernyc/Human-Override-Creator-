# LUT licensing — Phase 14

This directory holds the 3D LUTs the server applies via ffmpeg's `lut3d` filter when transcoding to MP4 (see `server/proxy.ts` `/api/transcode`).

## Status: ALL SLOTS REAL (2026-05-14)

All five slots now ship a real LUT — four sourced externally, one hand-authored. See the table below for source and license per file.

**Caveat re. slots 3 and 4:** these are *closest-available substitutes*, not literal Vision3 250D / Eterna 250D. The MIT-licensed YahiaAngelo collection doesn't contain those exact stocks. Until literal LUTs are sourced, the substitute stocks are documented per-row below. The UI labels are unchanged (still "Kodak Vision3 250D" / "Fuji Eterna 250D") because they match the user-facing convention; what's bundled is a related but distinct filmstock.

## Re. attribution

ARRI's LUT package historically ships free-to-use with the request that "ARRI LogC4" be mentioned somewhere in the credit/about of any tool that bundles their LUTs. We comply by:

1. Listing it in this file.
2. (Recommended) Add "Color conversion LUT: ARRI LogC4 (© ARRI)" to the app's About / Credits panel before public release.

If ARRI's current terms have changed, check arri.com/learn/lut for the live ToS before bundling in a public/commercial release.

## Do NOT commit

- Commercial LUTs (Lutify paid packs, FilmConvert, Dehancer, etc.)
- LUTs from anonymous-source torrents — provenance can't be verified
- LUTs you exported from a paid plugin's preview tier — license usually forbids redistribution
